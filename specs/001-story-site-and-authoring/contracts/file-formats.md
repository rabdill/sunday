# Contract: File Formats

The export boundary. Three committed file types.

| File | Owner | Hand-editable |
|---|---|---|
| `stories/*.md` | Shared — portal writes, author may edit | **Yes**; divergence detected and reconciled |
| `sunday.yml` | Author | **Yes**; the portal never writes it |
| `cast.yml` | Portal | **No**; generated |
| `.sunday/store.db` | Portal | Not a file format. Gitignored, disposable |

## Story file

```markdown
---
slug: the-lighthouse
title: The Lighthouse
published: 2026-08-04
occurs: 1921-03
characters:
  - Mara Vance
  - Elias Doyle
locations:
  - Portsmouth
tags:
  - epistolary
draft: false
---

The fog came in early that year, and with it the letters.
```

| Field | Required | Form | Meaning |
|---|---|---|---|
| `slug` | yes | `[a-z0-9-]+`, unique | Permanent address. |
| `title` | yes | string | Display title. |
| `published` | yes | `YYYY-MM-DD` | Orders the feed. |
| `occurs` | no | `YYYY`, `YYYY-MM`, `YYYY-MM-DD` | Orders the archive. Omit → undated. |
| `characters` | no | list of strings | Drives the diagram and the feed filter. **Never shown on the story's own page.** |
| `locations` | no | list of strings | Same role as `characters`. |
| `tags` | no | list of strings | Free text, managed identically to characters/locations for naming consistency (duplicate detection, rename); not published. |
| `draft` | no | boolean, default false | Removes the story from every generated page. |

### Build-fatal failures

Unparseable frontmatter, missing `slug`/`title`/`published`/body, slug collision (names both
files), malformed `slug` pattern, malformed date. Naming problems are never build-fatal.

## `sunday.yml` — settings

Hand-owned; the portal never writes it.

```yaml
title: Sunday
```

## `cast.yml` — generated export

Carries only what the published diagram needs.

```yaml
# GENERATED BY THE SUNDAY PORTAL — DO NOT EDIT.
# Relationships and display names are owned by the authoring store (.sunday/store.db).
# Hand edits will be overwritten on the next save; to change these, use the portal.

display_names:
  - name: Elias Doyle
    display_name: Doyle

relationships:
  - from: Mara Vance
    to: Elias Doyle
    description: sister
    directed: false
```

Profile descriptions are not exported — nothing on the published site displays a character's
biography, since cast pages are portal-only. A store rebuild recovers relationships and display
names from this file; a description exists nowhere outside `.sunday/store.db`.

### Contract

- An entry describes a name the stories already use; it cannot create one.
- `display_name` overrides diagram node labels only.
- Relationships appear in the network diagram as **stated** edges, distinct from co-appearance.
- Emitted in sorted order; deterministic.

## Reserved paths

| Path | Role |
|---|---|
| `stories/` | Corpus. Committed. |
| `sunday.yml` | Settings. Committed, hand-owned. |
| `cast.yml` | Export. Committed, generated. |
| `.sunday/store.db` | Local store. **Gitignored.** |
| `site/` | Generated site. **Gitignored.** |
